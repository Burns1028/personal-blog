# Projects Impressionist Earth — ImageGen Prompt Set

## Input roles

- `../earth-surface-master.png`: geographic structure reference. Preserve the equirectangular world-map layout, continent placement, and global coverage.
- `../../../../docs/superpowers/specs/assets/projects-activity-search-pagination-approved.png`: mood reference. Match the restrained deep-blue painterly Earth shown on the left edge; do not copy page UI.

## Shared constraints

Create a flat equirectangular planetary surface texture for a continuously rotating web globe. Preserve recognizable continent placement, global coverage, and a horizontally wrappable map composition. Output only the flat planetary surface filling the canvas. No sphere, outer space, stars, rim light, cast shadow, labels, borders, grid, text, watermark, satellite-photo microdetail, or interface elements. Keep the poles and both horizontal edges paintable so local post-processing can make the texture seamless.

## Candidate A — Deep-blue oil paint

Translate the surface into restrained impressionist oil painting: cobalt, ultramarine and ink-blue oceans; muted ochre, grey-green and ivory land; visible dry-brush marks; loose white-grey cloud strokes; simplified coastlines; low microdetail; museum-quality matte pigment on fine canvas. The result must remain clearly Earth but must not resemble a satellite photograph or 3D game material.

## Candidate B — Celestial atlas

Translate the same surface into a deep-blue celestial-atlas painting: ink-blue oceans, desaturated land, ivory cloud bands, subtle copperplate and hand-inked texture, restrained contrast, aged scientific illustration sensibility. Keep it painterly and non-photographic; do not add map labels, coordinates, borders, or symbols.

## Candidate C — Luminous night pastel

Translate the same surface into luminous night pastel: layered cobalt and midnight-blue pigment, soft blue-white cloud bloom, granular chalk texture, softened coastlines and atmospheric color mixing. Keep continents readable and the full map structurally stable; avoid fantasy colors, neon, photography, stars, and globe shading.
