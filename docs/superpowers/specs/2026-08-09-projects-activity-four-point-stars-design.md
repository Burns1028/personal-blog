# Projects 活动节点四角星芒设计

## 背景

Projects 页的活动轨道目前使用 9 px CSS 圆环标记活动日期。圆环体量小、结构机械，容易被理解为状态灯，与页面的真实星空、地球和卫星视觉不协调。

本次改造只替换活动节点的视觉标识，不改变活动数据、轨道布局、详情卡结构或既有交互。

## 目标

- 用四角恒星星芒替代现有圆环，让活动节点自然融入深空场景。
- 普通活动与最新活动保持明确但克制的状态差异。
- 在桌面端和移动端保持清晰，并继续支持鼠标、键盘和触屏操作。
- 使用 ImageGen 生成项目内可长期引用的透明位图素材。

## 视觉方案

采用“恒星星芒”方案：明亮星核、短四角星芒和低透明度圆形辉光。星芒应具有轻微摄影感和能量层次，但不能像亮片 emoji、卡通图标或界面状态灯。

生成两枚同构素材：

1. 普通活动星：冷蓝白色星核，外层带极淡青色辉光。
2. 最新活动星：暖白色星核，外层带克制的琥珀金辉光。

两枚素材必须保持相同的主体比例、星芒长度和视觉重心，只改变色温。四个方向的星芒以垂直方向略长、横向略短为宜；不添加圆环、轨道、文字、阴影底座或其他物体。

## ImageGen 素材流程

- 分别生成普通态与最新态，避免在一张图中生成多个不一致的图标。
- 以现有 Projects 页截图作为风格参考，不直接修改整页截图。
- 使用纯色绿幕背景生成，再通过本地工具移除背景并检查透明边缘。
- 最终输出方形透明 PNG；建议保留 128 × 128 px 文件，在页面中按 18–20 px 显示，以支持高像素密度屏幕。
- 项目内文件名固定为：
  - `public/assets/projects-activity-star-cyan.png`
  - `public/assets/projects-activity-star-amber.png`

生成提示词必须包含以下约束：无文字、无水印、无圆环、无行星、无背景星空、无地面阴影、无绿色主体元素，主体居中并保留安全边距。

## 页面接入

保留 `.activity-orbit__trigger` 的 28 × 28 px 可点击范围，将 `.activity-orbit__dot` 的圆环样式替换为透明星芒背景图。

- 普通节点使用冷蓝白素材，显示尺寸为 18 px。
- `.is-current` 节点使用暖金素材，显示尺寸为 20 px。
- 星体中心继续对齐轨道曲线，不改变现有六个节点坐标。
- 星芒本身不承载语义；日期、活动数量和详情卡仍提供完整信息。

## 交互状态

- 默认：保持清晰但不过亮，不与活动摘要争夺视觉焦点。
- Hover、键盘焦点或详情卡展开：亮度略增，整体最多放大约 8%，辉光稍微增强。
- 卫星定位最新活动：保留一次性脉冲，但脉冲作用于星芒外层辉光，不恢复圆环。
- 不持续闪烁、不旋转，避免干扰阅读。
- `prefers-reduced-motion: reduce` 下禁用缩放和脉冲动画，保留静态焦点轮廓。

## 响应式与无障碍

- 移动端时间线继续复用同一组星芒素材，星体中心对齐竖向时间线。
- 透明图像不得扩大布局盒，不得造成横向滚动。
- 触发按钮、`aria-expanded`、`aria-controls` 和详情卡关系保持不变。
- 键盘焦点轮廓应环绕整个 28 px 触发区域，不能只依赖颜色或图片亮度表示焦点。
- 图片加载失败时，节点仍保留一个与星核颜色一致的最小圆点作为 CSS 回退。

## 验收标准

- 页面中不再出现原有的描边圆环节点。
- 普通节点为冷蓝白四角星芒，最新节点为暖金四角星芒。
- 星芒在桌面端 1440 px、桌面端 2048 px 和移动端 390 px 视口中均清楚可辨。
- Hover、键盘焦点、触屏展开、点击外部关闭和 `Escape` 返回焦点继续正常工作。
- 详情卡打开后，节点仍与对应日期和轨道位置保持明确关联。
- 页面无新增横向溢出；启用减少动态效果后无缩放或脉冲动画。
- 自动化测试、类型检查和生产构建通过。

## 不在本次范围内

- 不重新设计活动详情卡。
- 不修改活动轨道曲线或节点位置。
- 不调整项目卡片、搜索、分页、地球或卫星素材。
- 不增加持续粒子动画、音效或新的活动类型图标。
