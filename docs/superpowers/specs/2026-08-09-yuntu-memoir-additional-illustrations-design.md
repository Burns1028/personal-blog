# 《云图回忆录》补充插图设计

## 目标

为《云图回忆录》补充三张概念插图，让 OLAP 的隐藏成本、Agent 的确定性边界，以及 AI 时代“先定义、后执行”的关系变得可见。插图只负责解释观点，不冒充真实项目现场或事实证据。

## 视觉方向

采用具体场景式编辑摄影：画面由真实器物、空间和动作构成，读者不依赖标签也能理解主要张力。三张图以克制的色彩、自然材质和中等观看距离形成系列感，但不共享同一种背景、构图骨架或表面纹理。

全系列禁止纸张、手稿、信件、墨迹、星空、星图、伪档案、标签墙、框线图、思维导图、发光 AI 大脑、品牌标识、伪产品界面和装饰性文字。不得生成 Burns 本人或真实同事，也不得把概念场景伪装成云图项目现场。

## 三个图位

### 1. OLAP 的隐藏账单

- **论证任务**：让“查询灵活”背后的 CPU、内存、SSD、热量和资源占用同时可见。
- **插入位置**：实习章节中“一个功能看起来漂亮，并不代表它就是最合适的选择”之后。
- **物理场景**：正在高负载运行的服务器内部或开放式工程工作台。CPU 散热器处于视觉中心，内存条、企业级 SSD、密集线缆和散热气流共同形成压力；远处只保留一个简洁的快速查询结果光面，不出现可读 UI 或数字。
- **构图**：横向 3:2，近景硬件清晰，热与负载通过灯光、风流和材料状态表现，不做爆炸图或零件标签。
- **文件名**：`14-olap-hardware-cost-concept-v1.png`
- **图注**：`灵活的查询把代价推到了 CPU、内存、SSD 和稳定性上。AI 生成的概念示意。`

### 2. Agent 进入生产前的边界

- **论证任务**：解释探索性 Agent Loop 与稳定交付 Workflow 不是二选一，而是处于不同区域、受不同约束。
- **插入位置**：正式入职章节中“成本是什么，谁来接住，谁来管控”之后。
- **物理场景**：自动化测试场与生产通道相连。开放测试区里，多台小型自主设备可以自由选择路径；进入生产区前，它们必须依次通过一个结构明确的校验闸门和窄通道。画面用空间边界表达控制，不画流程箭头。
- **构图**：横向 3:2，左侧开放但不混乱，右侧收束且稳定；没有文字、编号或警示标签。
- **文件名**：`15-agent-production-gate-concept-v1.png`
- **图注**：`探索可以留在开放区域，稳定交付的环节仍需要明确边界。AI 生成的概念示意。`

### 3. 先定义，再执行

- **论证任务**：解释 AI 执行能力增强以后，人仍要负责问题定义、尺度和验收标准。
- **插入位置**：AI 时代章节中关于信号、反馈与重新定义问题的段落之后。
- **物理场景**：精密工程工作台上，一双人的手正在用卡尺、量规和夹具确定零件标准；旁边的自动机械臂已经准备执行，但尚未动作。测量与约束是前景主角，机器执行位于次要位置。
- **构图**：横向 3:2，近距离但保留完整因果关系；不出现悬浮界面、文字说明或人脸。
- **文件名**：`16-problem-definition-workbench-concept-v1.png`
- **图注**：`执行越来越便宜以后，先把尺度和验收标准定义清楚，反而更重要。AI 生成的概念示意。`

## 生成与验收

三张图分别调用一次内置 ImageGen，使用各自独立提示词，不以一张图的构图替换另外两张。首轮生成后逐张检查：对象是否真实可辨、关系是否无需标签就能读懂、是否误入禁用元素、是否可能被读者误认为真实项目照片。

若某张图失败，只围绕一个明确问题重做一次，例如调整主体关系、减少抽象光效或修正器物逻辑。合格图片保存到 `yuntu-memoir-assets`，正文使用相对路径，并按出现顺序重新编号全部图注。发布前先运行文章只读校验；发布后检查桌面与手机端的图文节奏、图片加载和媒体状态。

## 完成标准

- 三张图各自只服务一个段落，移到另一篇文章会失去大部分含义。
- 不依靠标签、箭头、框线或大段文字解释关系。
- 不包含纸张、手稿、墨迹、星空和伪档案质感。
- 每张图都有准确 alt、明确图注和“AI 生成的概念示意”声明。
- 原有真实比赛照片不做生成式修改，Pico、老虎和比赛图片全部保留。
