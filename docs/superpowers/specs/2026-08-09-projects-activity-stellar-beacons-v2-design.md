# Projects 活动星核信标 V2 设计

## 结论

采用已确认的 A“星核信标”，但不照搬首页现成图标。节点继承首页的低饱和金属材质、克制金色、微型仪器感和精细光效，同时加入 Projects 页自己的冷青色技术气质。

此前生成的长镜头光斑方案被否决，相关素材与样式必须移除。

## 素材

使用内置 Image 2 分别生成两枚同构信标：

- 普通信标：冷青银色，中心为细小的切面菱形星核，四条短光芒，外围有少量微光与星尘。
- 最新信标：暖金色，结构、比例和光芒长度与普通信标一致，只改变材质色温。

素材约束：

- 最终文件为 256 × 256 px 透明 PNG。
- 星核位于画布几何中心，整体在 22–24 px 显示时仍能辨认出切面、短星芒和外围闪光。
- 光芒必须短、细、精确，不得再次形成长镜头光斑。
- 不得出现圆环、轨道、行星、文字、emoji、霓虹或 App 图标质感。
- 文件名为 `projects-activity-beacon-cyan.png` 与 `projects-activity-beacon-amber.png`。

## 轨道几何

轨道与节点必须共享一个贝塞尔曲线数据源。代码保存起点、两个控制点和终点，并从它同时生成：

1. SVG 的 `d` 路径。
2. 每个节点给定横向百分比时的精确纵向百分比。

禁止继续维护手写的 `[left, top]` 坐标对。节点的视觉中心必须落在轨道路径中心线上，桌面端不得存在肉眼可见的上下偏差。

## 页面表现

- 普通信标显示为 22 px，最新信标显示为 24 px，点击区域保持 28 × 28 px。
- 轨道线穿过信标中心，由不透明星核自然遮住交点，形成“信号钉在轨道上”的关系。
- Hover、键盘焦点或详情展开时，只增强亮度和外层微光，最多放大 6%。
- 卫星定位最新活动时播放一次短脉冲；减少动态效果时只提高静态亮度。
- 移动端节点中心对齐竖向时间线，不能改变详情卡交互。

## 验收

- 被否决的 `projects-activity-star-*.png` 不再存在或被引用。
- 两枚信标在 1440 px、2048 px 与 390 px 视口中材质清楚、色温统一、不像通用网页特效。
- 六个桌面节点的中心与轨道数学重合，最大几何误差小于 0.5 px。
- 页面无横向溢出；Hover、焦点、触屏、`Escape` 与卫星定位全部正常。
- 自动化测试与生产构建通过。
