# 首页 Three.js 粒子光流设计

日期：2026-08-22  
状态：用户已确认

## 背景

首页当前把一张带月球、地球和黑洞圆形镂空的宽光带位图，通过单个仿射矩阵映射到三个实时锚点。该矩阵只能同时匹配三个点，不能同时匹配三个天体的实时半径和轮廓。移动端改变天体比例后，月球右侧暴露出黑色月牙形缺口，地球汇合位置出现硬切边，黑洞端的发射方向也缺少自然的切线关系。

新增的 ImageMagick 粒子条只能增强路径中段。它不能删除母光带中已经存在的透明洞，也无法修复天体边缘的几何关系。因此，本次重构不再继续调整母光带位图，而是移除该运行时图层，用实时几何生成全部连接。

## 目标

- 保留现有月球、地球、黑洞、卫星、导航和桌面构图。
- 只重做三颗天体之间的连接系统。
- 月球、地球与黑洞各有一条独立光臂，三条光臂连接到同一个可见的中央发光点。
- 光流从天体真实可见边缘发出和进入，不再使用中心点与预裁圆洞假装连接。
- 桌面端和移动端共用同一套几何，只改变粒子密度、DPR 和帧率预算。
- WebGL、纹理解码或上下文恢复失败时，页面仍有无硬裁缺口的 2D 程序化连接。

## 非目标

- 不把现有三颗天体迁入 Three.js。
- 不改变首页文字、导航、联系方式或天体点击区域。
- 不增加自由相机、鼠标视差或用户可操作的 3D 轨道。
- 不复用现有带圆形镂空的母光带作为回退方案。

## 方案选择

采用“DOM 天体 + 单个透明 Three.js 光流画布”的混合架构。

现有月球和地球继续使用各自的 WebGL 表面画布，黑洞和卫星继续使用现有 DOM 图层。新的透明 Three.js 画布只负责光流，位于星空之上、天体之下。导航链接仍由 DOM 提供语义、焦点和点击能力。

没有选择全场景 Three.js，是因为它会同时改变天体纹理、点击层和桌面构图，风险超出本次修复范围。没有继续使用纯 2D Canvas 作为主实现，是因为大量旋转粒子、分层透明度和动态质量控制更适合由 GPU 批量处理。

Three.js 使用 `BufferGeometry` 保存实例属性，并用 `ShaderMaterial` 控制位置、颜色、尺寸、透明度和纹理采样。粒子不使用 `PointsMaterial`，避免手机 GPU 对点尺寸的硬件上限。每颗粒子使用一个实例化四边形，因此可独立旋转和缩放。

## 场景与坐标

### 正交坐标

使用正交相机，并让一个场景单位对应一个 CSS 像素。这样桌面与手机只有布局尺寸差异，不会产生透视缩短或镜头畸变。

渲染器尺寸取 `.home-cosmos__stage` 的实时边界。手机端 DPR 上限为 `1.5`，桌面端上限为 `2`。任何尺寸变化都由 `ResizeObserver` 触发，不在每帧读取布局。

### 实时天体轮廓

控制器直接测量以下可见轮廓，而不是读取当前的 2px 中心锚点：

- 月球：`.home-cosmos__sphere--moon`
- 地球：`.home-cosmos__sphere--earth`
- 黑洞：`.home-cosmos__black-hole-core` 与外层吸积环的可见半径

测量结果转换为舞台内的中心、横向半径和纵向半径。每个路径端点通过射线与椭圆边界求交得到，因此起点和终点永远落在实时天体边缘。

### 三臂枢纽路径

光流由三个三次贝塞尔段组成：

1. 月球右侧边缘到中央发光点。
2. 黑洞吸积环的右上切线点到中央发光点。
3. 地球左侧边缘到中央发光点。

中央发光点位于三颗天体围成区域的右侧，并在地球中心左侧 `1.25–1.55` 个地球横向半径处，根据舞台宽度在此范围内插值。它必须落在三颗天体的可见轮廓之外，地球光臂的可见长度不得小于地球横向半径的 `0.25` 倍。

三条曲线彼此独立但共享同一个精确端点，任何一颗天体都不是另外两颗之间的中转节点。中央点使用可见的蓝白柔光核心和克制的金蓝粒子晕，即使在静止截图中也能读出“三臂汇聚”的拓扑。月球光臂略向下弯，黑洞光臂沿吸积盘切线向右上弯，地球光臂较短并以蓝色为主。三臂进入中央点时允许保留各自方向，不强行拉成一条直线。

路径只依赖实时中心和半径，不写死某一款手机的像素坐标。

## 光流视觉

### 分层

每段光流由三层组成：

1. **柔光芯**：很窄的程序化 ribbon，保证路径在粒子稀疏时仍连续。
2. **主体粒子**：沿路径分布的实例化粒子，形成主要体积。
3. **高速微粒**：少量更亮、更小、速度更高的粒子，提供流动方向。

所有层使用加色混合，但限制最大亮度，避免地球入口和黑洞附近烧成白块。

### 颜色

- 月球光臂：暖白、浅金，接近中央点时过渡到冷白和浅蓝。
- 黑洞光臂：金色、橙色，接近中央点时过渡到青蓝。
- 地球光臂：蓝色为主，夹少量冷白高光。
- 中央发光点：蓝白柔光核心，外围只有克制的金蓝粒子晕，不形成遮挡天体的白块。

### ImageMagick 资产

ImageMagick 只生成单颗粒子纹理图集，不再生成整条光带。图集包含金色、橙色、暖白、过渡色和蓝色的软点、短划和不规则微粒。标准与 Retina 资产分别原生生成，固定随机种子，并在测试中检查透明度、非黑像素、尺寸、体积和可重复性。

粒子纹理没有圆形洞、天体剪影或固定路径，因此可以在任意实时曲线上重复使用。

## 渲染与性能

- Three.js 通过动态导入加载，不阻塞首页首屏 HTML。
- 一个实例化粒子 draw call 加最多三个 ribbon draw call，常态总 draw call 不超过 `6`。
- 桌面默认约 `1,800` 颗主体与高速粒子，目标帧率为 `45 fps`。
- 手机默认约 `900` 颗粒子，目标帧率为 `30 fps`。
- `saveData`、低端设备或宽度小于 `360px` 时约 `420` 颗粒子，目标帧率为 `24 fps`。
- `prefers-reduced-motion: reduce` 时不启动动画，只渲染一帧静态光流。
- 页面隐藏、开始导航或进入 bfcache 时暂停；恢复可见时重新测量并继续。
- 销毁时释放纹理、几何体、材质和 renderer，防止 WebGL 资源泄漏。

## 降级与错误处理

加载 Three.js、创建 WebGLRenderer、解码图集或恢复 WebGL 上下文任一步失败，都切换到现有 2D Canvas 的程序化贝塞尔光芯和粒子绘制。

2D 回退必须使用同一份实时天体轮廓和三臂枢纽路径数据，不能重新显示旧母光带。失败不会隐藏天体或导航。Three.js 初始化完成后才淡入新画布，避免先显示空白再闪烁。

## 组件边界

- `home-orrery-geometry.ts`：测量天体轮廓、求边缘交点、生成三臂枢纽路径。纯函数部分可独立测试。
- `home-orrery-streams-three.ts`：Three.js 场景、实例属性、shader、质量档位和生命周期。
- `home-orrery-streams-2d.ts`：共享几何的静态或失败回退。
- `HomeOrrery.astro`：只负责 DOM、控制器装配、运动状态和导航生命周期。
- ImageMagick 构建脚本：只负责粒子 atlas，不包含布局或路径逻辑。

现有 `home-orrery-particles.ts` 在迁移完成后拆除；保留其中可复用的颜色插值和生命周期测试，不继续扩张单文件职责。

## 本地验收与切换

本地开发环境直接使用 Three.js 新实现，不设置查询参数或双版本入口。施工时同步删除运行时母光带 DOM、仿射矩阵代码和对应预裁资产引用。

本地完成手机与桌面截图验收后，由用户确认是否发布。用户确认前不修改阿里云生产环境；确认后通过现有原子 release 流程一次性发布完整实现。

## 测试与验收

### 自动测试

- 三条贝塞尔段的天体端点落在对应椭圆边缘，误差不超过 `0.5px`。
- 三条贝塞尔段共享同一个中央发光点，端点误差不超过 `0.5px`。
- 中央发光点位于三颗天体轮廓之外，地球光臂可见长度不小于地球横向半径的 `0.25` 倍。
- 任意 `320–1,600px` 舞台宽度下，路径和粒子边界不产生横向溢出。
- 退化或零尺寸轮廓返回失败并启动 2D 回退。
- Three.js 加载失败、WebGL 创建失败、纹理解码失败、上下文丢失和销毁后异步完成均不会继续绘制。
- 质量档位、DPR、暂停、恢复和资源 `dispose()` 均有行为测试。
- 粒子 atlas 固定种子可重复，并含真实透明彩色像素。

### 浏览器验收

检查 `360×800`、`393×852`、`430×932` 和 `1440×900` 四个视口，并单独截取月球出口、中央发光点、地球出口和黑洞出口。

通过标准：

- 月球右侧没有黑色月牙、直线切口或透明洞。
- 黑洞光流沿吸积环切线发出，不从黑洞中心穿出。
- 中央发光点清晰可见，三条独立光臂分别连接月球、地球和黑洞，不能读成“月亮到地球、地球再到黑洞”的串联。
- 地球入口没有蓝色硬片、三角尖角或亮度断层。
- 粒子运动方向一致，静止截图也能读出完整连接。
- 桌面端三颗天体的中心与尺寸相对当前生产版本偏差不超过 `1px`。
- 手机与桌面均无横向滚动，页面控制台无运行时错误。

## 发布与回滚

本地验收通过且用户明确确认后，使用现有阿里云原子 release 流程发布。若生产环境出现 WebGL 兼容性问题，回滚到上一份完整 release；运行时自动降级仍使用共享几何的 2D 回退，不恢复旧母光带位图。
