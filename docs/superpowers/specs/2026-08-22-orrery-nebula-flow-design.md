# 首页星尘汇流视觉设计

## 背景

当前版本已经恢复“中央节点连接月亮、地球和黑洞”的正确拓扑，但三条连接仍由连续亮色带和高度收束的曲线构成。静态截图中，它们容易被读成机械的 `Y` 字接头或三根电线，中央亮点又进一步放大了这种尖锐感。

本次只重做连接层的视觉语言，不改变首页排版、三个天体的位置与尺寸、导航关系、星空背景、球体材质和移动端文档流。

## 目标

- 保留一个中央汇聚区，以及分别来自月亮、地球和黑洞的三股独立光流。
- 移除肉眼可见的连续线芯，不再出现清晰的 `Y` 字轮廓。
- 让每股光流具有宽度、层次、疏密和颜色变化，读起来像星尘、能量或物质流，而不是描边曲线。
- 中央区域表现为小型金蓝星云。三股光流在这里自然交叠，但依旧能够辨认各自来源。
- 手机端和电脑端使用同一套生成逻辑，并根据画布尺寸调整密度、宽度和亮度。
- 保留低性能设备、资源加载失败和 WebGL 上下文丢失时的 2D 降级能力。

## 采用方案

采用“星尘汇流”方案。现有三条 Bézier 曲线只作为不可见的运动骨架，不再直接绘制成连续光带。

每股光流由三层组成：

1. **外层尘雾**：粒径小、透明度低、横向离散范围大，负责形成柔和的体积感。
2. **中层星尘**：数量最多，沿曲线形成不规则密度带，颜色随行进位置渐变。
3. **亮点碎片**：数量少、亮度高、尺寸差异明显，用于打破均匀和规则感。

三层均不能形成从起点贯穿终点的连续实线。任何背景雾带的中心透明度都必须足够低，不能在截图中重新组成线芯。

## 路径与构图

三股光流继续共享同一个逻辑汇聚中心，但粒子不会全部落在同一个像素：

- 月亮流从月面朝中央方向的边缘离开，先略微下沉，再散入汇聚区。颜色由暖金过渡到冷蓝。
- 地球流最短，呈蓝白色扇形喷流。靠近地球时更宽、更柔，进入汇聚区时逐渐收窄。
- 黑洞流沿吸积环外切方向离开，保留橙金主色，弧度最大、尘雾最厚，接近汇聚区时混入少量青蓝。

三条运动骨架的终点继续一致，但粒子横向偏移会在终点前逐渐收束到一个有限半径的星云区域，而不是尖锐的单像素交点。汇聚区半径按舞台短边计算，并设置手机端和电脑端上限，避免在小屏过亮或在大屏过小。

## 中央星云

中央区域不再使用一个明显的圆形发光按钮。它由以下元素构成：

- 一个尺寸克制的蓝白柔光核心；
- 一圈不完整、非对称的金蓝尘雾；
- 少量绕核心缓慢漂移的亮点；
- 三股光流接近终点时的交叠颜色。

核心可以清楚标记“汇聚”，但不能形成十字星、圆形徽章或高亮焊点。静止状态也必须看得出三股流汇入同一区域。

## 粒子分布

粒子分布由确定性随机种子生成，保证刷新、重新测量和浏览器恢复后不会整体跳变。

每个粒子记录：所属光流、路径进度、速度、纵向偏移、横向偏移、尺寸、旋转、透明度、颜色角色和图集单元。横向偏移使用多峰分布，而不是均匀分布：多数粒子靠近流体中心，少量粒子形成宽散点。沿路径的密度再叠加缓慢变化的团簇函数，避免出现等距点列。

靠近天体和汇聚区时使用平滑遮罩：

- 天体出口不能露出硬矩形、月牙裁切或黑色缺口。
- 汇聚区前的横向散布逐渐缩小，但保留少量绕行粒子，避免三股流形成尖角。
- 粒子尺寸和透明度不能同时在同一位置达到峰值，防止出现烧白色块。

## Three.js 渲染

继续使用一个透明的 Three.js 画布和实例化粒子，不引入新的 3D 场景、后处理管线或大型纹理。

移除当前连续 ribbon 网格。粒子实例按视觉层分组，通过不同的透明度、尺寸和横向散布生成体积。现有 4×4 透明粒子图集继续复用；本次只调整图集单元的选用比例，不新增母光带位图。

渲染保持加色混合，但限制单粒子最大亮度。中央星云使用独立的轻量实例组或小型 shader 平面，不增加可见边框。动画只更新时间和强调状态，不在每帧读取布局。

## 2D 降级

2D 版本使用相同的几何快照和确定性粒子分布。它不绘制连续 `stroke()` 线芯，而是绘制低透明度尘雾点、中层星尘和亮点碎片。中央星云使用多个偏心径向渐变和少量静态亮点构成。

在 `prefers-reduced-motion`、省流量模式或页面暂停时，保留一帧静态星尘汇流，连接关系不能消失。

## 响应式与性能

- 小于 `360 px` 或低性能设备：降低粒子总量、光流宽度和刷新率，保留三层比例与中央星云。
- `360–767 px`：保持完整三层，限制散点外扩，避免触碰画布边缘或造成横向溢出。
- 大于 `767 px`：提高尘雾和碎片数量，允许黑洞流具有更宽的外层散布。
- 设备像素比继续封顶；跨显示器或尺寸变化时重新选择质量档位。
- 不改变三个天体和卫星的 CSS 定位值。

## 错误处理

- 几何无效时清空连接画布，不绘制错误路径。
- 粒子图集加载失败、WebGL 初始化失败或上下文丢失时，替换画布并启动 2D 降级。
- 降级过程继续传递当前几何、运行状态和交互强调状态。
- 页面销毁或异步准备被取消时，每个后端只释放一次。

## 验收标准

- 截图中不存在贯穿任一光流的连续亮线芯。
- 中央区域不能被读成机械 `Y` 字、三叉电线、十字星或焊点。
- 三股光流在静态截图中仍能分别追溯到月亮、地球和黑洞。
- 月亮出口无月牙硬裁；地球入口无硬切边；黑洞流沿吸积环切线离开。
- 金色、蓝色与青白色之间的过渡自然，中央区域不过曝。
- 在 `360×800`、`393×852`、`430×932` 和 `1440×900` 视口进行真实浏览器截图验收。
- 所有视口无横向溢出，控制台无新增错误。
- 2D 降级、减少动态效果、页面暂停与恢复均保留正确的三股汇流结构。
- 全量测试、Astro 检查和正式构建通过后，才交给用户确认；用户确认前不部署阿里云。
