## 2. 统一施工原则

### 2.1 ImageGen 与代码各自负责什么

所有具有材料感或具象叙事的位图由 ImageGen 重新生成：纸张星图、月面纹理、深空、地球和卫星。生成后的源图必须进入项目，不能只留在临时目录。

所有需要精确响应、交互或无损缩放的元素由代码生成：搜索框、分页、GitHub Octocat、轨道曲线、节点、信号波、焦点态和阅读遮罩。不能把输入框、文字、页码或 SVG 轨道烘焙进背景图。

### 2.2 素材生产链

1. 使用获批效果图作为构图参考，用内置 ImageGen 生成无文字的主素材。
2. 卫星和月球使用纯色抠图底生成，再用标准去色脚本转换为透明 PNG；地球只生成一张无光照的 2:1 表面母版，由构建脚本投影为透明球面旋转帧，避免 12 张独立生成造成纹理跳变。
3. 将主素材保存在 `design-source/archive-v2/`，保留原始分辨率和提示词记录。
4. 使用 Sharp 构建脚本输出桌面、平板、移动端 WebP；不得在运行时裁图或合成大位图。
5. 用元数据测试检查尺寸、透明通道、字节上限和必需文件。

### 2.3 动态边界

- 页面进入动画必须等待首页产物的跨文档展开动画结束。
- Projects 左侧地球旋转是本轮唯一允许的长期环境动画。保留现有的 12 帧 Canvas 混合方案、`20s` 一周和 `24fps` 绘制上限；只替换为质量更高、由同一张 ImageGen 地球表面母版推导出的帧。
- 地球帧必须按顺序渐进解码，并在 `burns:page-settled` 后才启动；元素离开视口、页面隐藏、开启 `Save-Data`、减少动态或移动端时暂停或使用静态首帧。
- 除地球旋转外，不做持续粒子、持续 Canvas 绘制或高频背景动画。
- 动画只使用 `transform`、`opacity` 和 SVG `stroke-dashoffset`。
- `prefers-reduced-motion: reduce`、省流量和移动端保留静态构图。
- 页面隐藏后不得继续执行 `requestAnimationFrame`。

## 3. Writing：居中的夜间写作档案

### 3.1 构图

- 星图连续覆盖整个视口，不能缩成右侧插图。
- 文章内容列宽为 `900–980px`，以视口中心线为轴居中。
- 顶部月相序列、搜索框、文章列表和分页共享同一中心轴。
- 正文区域使用无边界的暖纸阅读遮罩降低星图对比度；遮罩必须羽化，不能看成卡片。
- 所有断点共用同一套服务端分页，每页显示 4 篇；移动端只改变排版，不用视口宽度改变页数，避免同一个 URL 在不同设备上指向不同内容。

### 3.2 月相

- 顶部月相序列由 8 个独立、完整、风格一致的月相组成，不使用一张难以精确裁切的长条图。
- ImageGen 只生成一颗高质量的版画式满月母版；8 个天文相位由构建脚本基于同一母版生成，以保证纹理、直径和明暗边界一致。
- 每篇文章根据 `publishedAt` 计算相位索引。文章发布月相一经确定，不随访问日期改变。
- 月相资产必须保留完整圆盘外轮廓；弦月也不能被裁到边缘或与相邻月相混杂。

### 3.3 搜索与分页

- 搜索使用 GET 参数 `q`，占位文案固定为“搜索文章、主题或关键词”。
- `⌘ K` / `Ctrl K` 聚焦搜索框；Enter 提交；清空后回到未过滤列表。
- 搜索范围为标题、摘要、导语和标签；忽略大小写和首尾空白。
- 分页使用 GET 参数 `page`，查询条件必须在翻页链接中保留。
- 只渲染真实存在的页码；数据不足一页时保留当前页 `01`，不伪造可点击的 `02`、`03`。
- 无结果时保留背景与搜索框，显示一句安静的空状态，并提供清空搜索入口。

### 3.4 动画

- 页面落定后，顶部月相序列在 `360ms` 内淡入并上移 `6px`。
- 搜索框随后在 `220ms` 内显现；文章行以 `45ms` 的间隔依次出现，单行时长 `260ms`。
- 翻页和搜索结果通过原生 View Transition 让列表旧内容淡出 `120ms`、新内容淡入 `180ms`，背景星图不参与过渡。
- 文章月相没有持续运动；悬停文章时只允许 `scale(1.035)` 和轻微对比度提升。

## 4. Projects：从地球驶向当前活动的轨道

### 4.1 构图

- 深空覆盖整页；地球只在左侧露出弧面，是出发点。
- 项目卡片位于中央工作区；搜索框位于项目标题行右侧；分页位于卡片区与轨道之间。
- 轨道从地球边缘出发，穿过页面下方的负空间，终点连接右侧卫星。
- 卫星是当前时刻的接收器，不是装饰贴纸。
- 项目卡继续使用 GitHub Octocat，不能用书本图标或 ImageGen 生成的近似商标。

### 4.2 聚合活动

- 时间线显示“最近几天推进了什么”，不展示 SHA、分支、HEAD 或每一次 commit。
- 展示最近 6 个有活动的日期，每个节点包含日期、活动数和一句代表性摘要。
- 活动来源与界面解耦。第一阶段提供受保护的手动写入接口；以后 GitHub、文章发布或其他来源只作为适配器接入同一数据表。
- 原始活动存入 SQLite，按日期在服务端聚合。活动字段为发生时间、项目、类型、标题、摘要、可选链接、来源和幂等键。
- 没有活动时仍保留地球、轨道和卫星，轨道上显示“等待下一次信号”，不能伪造记录。

### 4.3 搜索与分页

- 搜索使用 GET 参数 `q`，占位文案固定为“搜索项目、技术或状态”。
- 搜索范围为项目标题、slug、摘要、语言、状态和标签。
- 桌面端每页显示 3 个项目；平板与移动端保持同一数据分页，只改变列数。
- 分页只控制项目卡；底部活动轨道始终显示最近活动，不随项目翻页。
- 页码只反映真实项目数量。

### 4.4 动画与卫星交互

- 地球保持现有的缓慢自转，作为“从已知出发”的持续生命感；它不能因背景替换、性能优化或移动布局重构而被删除。桌面能力允许时旋转，移动端、省流量和减少动态模式使用同一组帧的静态首帧。
- 页面落定后，轨道以 SVG 描边方式在 `760ms` 内从地球向卫星绘出；节点按 `70ms` 间隔显现。
- 卡片只做 `translateY(-2px)` 的悬停响应，不增加发光粒子。
- 卫星是可聚焦按钮，语义为“定位到最新活动”。点击、Enter 或 Space 后：
  1. 卫星在 `720ms` 内完成两次逐渐减弱的上下位移：`0 → -8px → 0 → -4px → 0`；
  2. 两道信号弧依次扩散并淡出；
  3. “今天 / 活动汇入”节点闪亮一次并获得程序焦点；
  4. 移动端如果节点不在视口中，使用 `scrollIntoView({ block: "nearest" })`。
- 减少动态模式下不移动卫星，只改变当前节点轮廓与辅助文本。

## 5. 响应式

### 5.1 Writing

- `>= 1200px`：完整居中构图，星图两侧都可见。
- `768–1199px`：内容列宽缩至视口减 `64px`，月相与元数据不重叠。
- `< 768px`：文章元数据移到标题下方，月相固定在行尾；搜索框占满内容宽度；分页允许水平滚动但不换行。

### 5.2 Projects

- `>= 1200px`：两列项目卡、完整轨道和右侧卫星。
- `768–1199px`：卡片改为单列，地球与卫星更多裁到边缘，轨道仍绕开卡片。
- `< 768px`：轨道改为纵向时间线，卫星位于时间线末端；地球只保留一小段蓝色弧面；背景与卫星静态化。

## 6. 性能与资源预算

- Writing 首屏位图总传输目标不超过 `900KB`；Projects 不超过 `1.1MB`。
- 单张背景 WebP：桌面不超过 `550KB`，移动端不超过 `280KB`。
- 单张透明地球帧不超过 `140KB`，12 帧总量不超过 `1.6MB`；透明卫星不超过 `120KB`；单个月相不超过 `28KB`。
- Projects 保留 12 帧 Canvas 地球循环：静态首帧立即可见，其余帧只在页面落定后按顺序解码；移除次级实时星场，改用静态 ImageGen 深空背景。
- 所有非首屏图片使用 `loading="lazy"`；首屏主图使用正确的 `fetchpriority` 和尺寸属性，避免布局偏移。

## 7. 验收条件

- 两页在 `1440×900`、`1024×768`、`390×844` 下保持设计关系和正文可读性。
- Writing 内容列在桌面视口中心，搜索和分页不改变中心轴。
- 每篇文章的月相由发布日期决定，8 个相位均为独立完整图形。
- Projects 搜索、真实分页、活动聚合、手动写入接口和卫星定位交互均可用键盘操作。
- Projects 在具备动画能力的桌面环境中保持缓慢旋转的地球；在移动端、省流量和减少动态模式中稳定显示同源静态首帧。
- 无 SHA、HEAD、分支或伪造活动出现在公开时间线。
- 减少动态、省流量、页面隐藏和移动端降级均通过测试。
- `npm run test:content`、`npm run check`、`npm run build` 全部通过。
