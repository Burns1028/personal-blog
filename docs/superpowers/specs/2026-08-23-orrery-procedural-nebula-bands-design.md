# 首页思想星系程序化星云光带设计

## 目标

把月球、地球、黑洞到公共汇点的三条连接从“重复火花粒子”升级成有体积、边缘自然消散的星云光带。公共汇点移动到三个天体之间更居中的位置；地球支路从公共汇点自然转弯，准确进入现有蓝白闪光；黑洞支路使用浅金色，不出现红色或橙红色火花。

## 已确认的根因

1. 当前汇点 X 坐标由 `earth.x - earth.rx * offset` 决定，视觉上过度贴近地球，不是真正位于三颗天体之间。
2. 地球路径的数学起点已经是 `17.36% / 39.58%` 的蓝白闪光标记，但贴图粒子在起点附近稀疏且透明。画面中第一段可见光点出现在标记下方，造成“连接歪了”的视觉事实。
3. 主体由同一张粒子图集重复铺成，显露出火星、纸屑和纹理重复感，无法形成星空或星云的连续体积。
4. 黑洞支路的代码色值是橙红色，和金色吸积盘及整页冷暗色调冲突。

## 几何设计

- 公共汇点使用三颗天体中心的加权重心：月球 `25%`、地球 `50%`、黑洞 `25%`。它仍略向地球侧偏以维持构图张力，但明显离开地球边缘，进入三者之间。
- 三条路径仍是互相独立的三叉结构，终点严格共享同一个汇点；禁止改成月球到地球、地球到黑洞的串联关系。
- 地球路径继续把现有蓝白闪光标记作为真实端点。以端点的椭圆切线决定最后一段方向，使从汇点看过去的光带先向右上弯，再顺势进入蓝色闪光，而不是直线扎入地球或在闪光下方结束。
- 黑洞路径继续从吸积环右上切线发出，但中段向新的公共汇点收束，不保留旧的下坠式终段。
- 不改变月球、地球、黑洞、卫星、首页文案和导航的 CSS 位置或尺寸。

## Three.js 渲染设计

- 每条支路由独立的采样带状网格承载。网格只定义中心曲线、宽度和进度，不使用拉伸位图。
- 片元着色器程序化生成三层质感：宽而低对比的星云雾、较窄的柔光主体、极少量高光星尘。边缘使用噪声扰动和羽化，不出现硬描边、连续一像素线或清晰三角带边缘。
- 光带在天体端和公共汇点端都保持覆盖，不能依赖随机粒子恰好落在端点。地球端由蓝白闪光素材盖住接缝。
- 颜色：月球为暖金到蓝白；地球为深蓝到蓝白；黑洞为香槟浅金到蓝白。三条支路在公共汇点统一为蓝白核心，不允许红色。
- 动画只缓慢推动噪声和微弱亮度呼吸，不让粒子像火花一样高速飞行。
- 保留现有响应式 DPR、帧率、WebGL context-loss 和 2D fallback 生命周期。

## 2D fallback

Canvas 2D 使用同一组几何路径和颜色，分三次绘制宽雾、柔光主体和窄核心，并使用模糊与透明度制造羽化；少量星尘只做点缀。fallback 不追求与 shader 像素一致，但必须保留居中汇点、地球弧线、浅金黑洞支路和无红色约束。

## 验收标准

1. 桌面 `1440×900` 和手机 `393×852` 中，公共汇点明显位于三个天体之间，不再贴着地球。
2. 地球支路最后一段可清楚看出转弯并进入蓝白闪光；闪光与光带之间没有黑缝、错位或下方假连接。
3. 黑洞支路为浅金色并完整到达公共汇点，不出现红色。
4. 三条支路都能追溯到同一汇点，但汇点没有硬 Y、焊点或巨大白团。
5. 主体读作星云光带，而不是成排火星、重复纸屑或廉价粒子。
6. 页面无横向溢出，Three renderer 正常，控制台没有新错误；2D fallback 也满足几何和色彩契约。
7. 只在本地 `4322` 验收，不部署阿里云。
