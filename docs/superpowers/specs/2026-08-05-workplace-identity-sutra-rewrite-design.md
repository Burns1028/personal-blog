# 《应无所住，而生其心》第二版重写设计

## 目标

保留文章关于职业身份的判断，但不再把判断完整地铺成一套模型。新版从一段真实的自我介绍出发：字节、高绩效、顶级 offer，这些都是作者确实拥有、也确实会拿来介绍自己的坐标。文章慢慢追问，为什么这些话说得越顺，反而越容易忘记它们只能描述一段经历。

读者仍然应当获得“角色会变化，价值要在行动里反复选择”这一判断，但不通过表格、定义和总结句直接交付。判断要从经验、迟疑和经文之间长出来。

## 叙事推进

### 1. 一段太顺的自我介绍

从作者已经提供的真实材料开始，不虚构晋升、失败或情绪场景：

> 字节的同学，拿过高绩效，也拿到过顶级 offer。

承认这些成绩真实、重要，也承认它们很好用。问题不在于说这些话，而在于说久了以后，会不会开始依赖它们回答“自己是谁”。这里不急着提出“自我叙事模型”。

### 2. 当结果没有完成证明

写一种普遍但不冒充个人经历的时刻：终于拿到想要的评价，轻松一阵，下一轮很快又开始。人原以为结果会结束证明，结果只是提高了下一次证明的门槛。

这一段才慢慢长出判断：很多身份变化并非事件改造了人，而是过去用来解释自己的话忽然不够用了。最多使用一次“自我叙事”，不用“异常输入、预测模型、模型失配”等连续系统术语。

### 3. 经文照进具体困惑

先想起《心经》的“照见五蕴皆空”。不单独定义“条件性”，而是直接写一份绩效由哪些人、项目和时机共同形成。由此得到：成绩是真的，却不能独自完成对一个人的解释。

再进入《金刚经》的“应无所住而生其心”。重点写“生其心”：放下永久证明的冲动之后，工作并没有停止。仍然争取结果、维护权益、承担选择，只是不再要求一个结果替后面的生命作结论。

### 4. 价值不是新的自我介绍

保留“从角色认同到价值承诺”的判断，但不用标题宣布它，也不使用对照表。“有好奇心、愿意探索、敢于负责”仍可能变成一套更漂亮的身份包装。价值真正出现的地方，是碰到未知时是否愿意靠近，证据变化时是否肯改，作出选择以后是否把后果接回来。

结尾回到开头的自我介绍。那些成绩不需要删掉，也不需要用“这些都是我，也都不是我”来否定。它们可以留下，只是不再站在句号的位置。

## 措辞约束

- 全文控制在 2,200–2,700 字，宁可少讲一层，不把所有推理解释完。
- 使用 3 个以内的二级标题；不使用表格、编号框架或“读者可以问三个问题”。
- “身份认知、自我叙事、价值承诺、解释模型、社会坐标”等抽象词，每个最多出现两次；同一段不连续出现两个以上。
- 删除标准化转折：“这提供了一个很实用的检查方式”“放到职业语境里”“所以，更准确的变化是”。
- “不是 X，而是 Y”全文最多两次；避免连续对称句和每节末尾的金句。
- 允许一两处句子没有彻底收束，让感受先停留，不立即追加解释。
- 不故意制造错字、病句和标点混乱。人味来自观察和迟疑，不来自表面粗糙。
- “我”只承载真实材料与理解边界，不虚构个人晋升、失意、会议或对话。

## 保留的获得感

文章虽然不展示框架，仍要让读者隐约分开三件事：发生了什么，自己把它解释成了什么，接下来仍愿意怎样行动。

必须保留两个可以带走的判断，但只各出现一次：

1. 一个结果可以说明一段经历，不能替整个人下结论。
2. 价值不是更好听的自我介绍，是下一次遇到事情时仍愿意怎样做。

## 插图

继续使用三幅来源明确的历史资料图，不生成人造经卷。图像只提供时代与材料感，不承担解释文章结构的任务。插入点在经文自然出现之后，不为每节平均分配。

## 通过标准

- 开头的个人材料全部来自用户已明确提供的事实。
- 删除所有表格，二级标题不超过三个。
- 读起来像判断在行文中逐渐形成，而不是作者先知道答案再逐项证明。
- 《心经》《金刚经》分别改变了文章的理解，不是文化装饰。
- 结尾回到字节、高绩效和 offer，但不否定成绩，也不以新身份替换旧身份。
