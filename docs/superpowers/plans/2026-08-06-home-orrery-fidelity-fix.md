# 首页思想星系母图对齐施工计划

**目标：** 首页右侧思想星系在 1600×732 基准画布上与 `docs/superpowers/specs/assets/home-orrery-motion-approved-v1.webp` 保持同一构图、尺寸、纹理、光向和连接关系，同时保留克制的旋转与粒子流动动画。

**原则：** 母图只作为离线设计源。运行时使用从母图确定性拆出的透明独立图层；静态基准层负责视觉一致，动画层只提供低幅度运动，不重画星体、不改变母图光影。

## 验收清单

- [x] 连接关系是两条独立支流在地球左缘汇合：黑洞→地球为宽金色主流，月球→地球为窄珍珠蓝支流。
- [x] 连接带有母图的体积、宽度、密度、收束和粒子方向，不再是穿过三颗星体的细虚线。
- [x] 地球尺寸与母图一致；深靛蓝和金色裂纹纹理一致；青蓝辉光只集中在左上连接处，右侧和下缘不出现均匀光圈。
- [x] 月球尺寸与母图一致；暖金、高反差坑纹和不对称受光一致，没有透明边距造成的缩小。
- [x] 黑洞的暗核、光子环、外侧非均匀旋涡和左上延伸形态与母图一致，不再使用扁平横向圆盘。
- [x] 三颗星体旋转时没有虚影、双轮廓、黑色方块或整张背景跟随运动。
- [x] 页面跳转展开动画只携带选中的独立星体，不携带母图背景、月相带或其他页面内容。
- [x] `prefers-reduced-motion`、省流模式、后台页面暂停仍然有效。

## 施工步骤

### 1. 先写失败测试

- 将粒子路径测试改为 `sampleBlackHoleToEarthPath` 与 `sampleMoonToEarthPath` 两条路径，验证二者分别起于黑洞/月球并共同终止于地球。
- 为 v4 素材添加尺寸、透明角、有效像素边界和运行时禁用整张母图的断言。
- 为 DOM 图层添加静态母图层、低透明动态纹理层和固定定向辉光层断言。

### 2. 确定性拆层

- 从 1600×732 母图按已测坐标裁出无透明边距的月球与地球圆形基准层。
- 按母图亮度与颜色键控提取：地球左侧定向青蓝辉光、黑洞光子环与外场、两条连接粒子河。
- 输出到 `public/assets/home-cosmic-system-v4/`，保留标准与高分辨率 WebP；构建脚本可重复生成。

### 3. 重构运行时合成

- 母图基准层保持固定并主导视觉；运动纹理副本仅以低透明度在圆形遮罩内缓慢位移。
- 地球定向辉光、黑洞外场和连接基底固定；月球/地球纹理与黑洞内环分别在独立遮罩内运动。
- Canvas 改成两组分支粒子，只叠加少量动态亮点与短尾迹。

### 4. 视觉迭代

- 浏览器固定为 1600×732，逐项对照母图检查几何、颜色、亮度和边缘。
- 每轮只调整一个变量；全部验收项通过前不宣告完成。

### 5. 回归

- 运行首页聚焦测试、完整内容测试与生产构建。
- 检查首页静态、悬停、选中、跳转展开、返回首页、移动端与 reduced-motion。
