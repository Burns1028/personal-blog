# Writing 分类筛选与二级目录

目标：在现有搜索框下方加入一级主题筛选，选中主题后展开二级文章目录，点击标题直达正文。

交互沿用现有纸张、墨色、金棕色细线。主题用可换行的文字导航，显示文章总数；目录用可收起的原生 details 元素。全部文章默认不展开目录，避免重复展示全文列表。所有操作使用普通链接与 GET 表单，关闭 JavaScript 仍可使用，浏览器返回可恢复状态。

分类从现有文章标签推导：AI Infra、Agent / RSI、读书笔记、产品与设计、工作与生活。明确分类可在发布标签中填写与主题同名的标签覆盖自动判断。未匹配文章归入工作与生活，确保不丢文章。不修改生产数据库。
