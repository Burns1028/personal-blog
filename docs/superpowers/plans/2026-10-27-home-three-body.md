# 首页三体运动实现计划

**目标：** 让首页三个导航星球相互牵引、不规则绕行，同时保持易于点击及首屏性能。

**实现：** 单独的无依赖数值模块负责软化引力、弱中心约束、Velocity Verlet 积分和镜头适配；DOM 控制器只负责固定时间步、transform、尺寸缓存及销毁。HomeOrrery 复用现有可见性和导航生命周期。

1. 为三体计算添加行为测试：动量与能量稳定、第三个物体影响轨迹、长时间无发散、大小不同的星球在桌面/手机视口内。先运行，确认因模块尚未实现失败。
2. 实现 `src/lib/home-three-body.ts` 中的状态、积分、投影及 DOM 控制器，运行上述测试。
3. 在 `HomeOrrery.astro` 中接入启动/暂停/销毁、鼠标和聚焦交互，在现有 CSS 中标记运动元素。将球面尺寸测量缓存到 ResizeObserver，避免移动时逐帧读取布局。
4. 运行内容测试、生产构建和真实浏览器检查；确认三者均在移动，移入/聚焦后停住，移出后恢复，入口可点击，手机不溢出，减少动态效果保持静态。检查 Writing 仍仅加载自己的轻量样式。
5. 按既有博客发布流程部署，通过 health 和线上浏览器复查。
